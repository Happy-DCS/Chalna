## 0. 요약

- **무엇:** 향수 브랜드 **Chalná**의 첫 컬렉션 **"Parts of Us"** 프로모션 사이트입니다. 고전 문학 5편(데미안, 노인과 바다, 오만과 편견, 향수, 고도를 기다리며)을 향 5종으로 풀어냈습니다.
- **상태:** 디자인과 동작이 모두 확정된 **완성 시안**입니다. 화면 5종과 1분 대기 후 첫 화면 복귀까지 동작합니다.
  - 화면: 봉투 인트로 → 편지 → 컬렉션 메인 → 상세 5종 → 브랜드 스토리 6페이지 → Contact
- **소스 구조:** 프레임워크와 빌드 도구가 없습니다. 바닐라 HTML/CSS/JS **한 파일**(`src/index.html`, 약 1,350줄)과 `src/assets/` 이미지 폴더가 전부입니다.
- **화면 기준:** **2560 × 1440 고정 스테이지**를 브라우저 크기에 맞춰 통째로 확대·축소합니다. 반응형 레이아웃이 아니며, 전시용 대형 화면(키오스크)을 전제로 합니다.
- **개발자가 할 일 (권장 우선순위):**
  1. `dist/Chalna_PartsOfUs.html`을 열어 완성 동작을 확인합니다.
  2. 아래 **§6 "알려진 이슈"**를 정리합니다.
  3. 배포 형태(전시 PC 로컬 실행 또는 웹 호스팅)를 정합니다.
  4. 필요하면 프레임워크로 옮깁니다. 이때 **§5 "확정된 디자인 결정"을 반드시 유지**해 주세요.

## 1. 패키지 구성

```
Chalna_PartsOfUs_DevHandoff/
├── README.md                 ← 이 문서 (개발자 전달서)
├── src/
│   ├── index.html            ← 유일한 소스 (HTML + <style> + <script>)
│   └── assets/               ← 이미지 전부 (§4)
├── tools/
│   └── build_single.py       ← 이미지를 base64로 넣은 단일 HTML 빌드
└── dist/
    └── Chalna_PartsOfUs.html ← 빌드 결과물 (약 23MB, 더블클릭으로 열림)
```

### 실행

- **개발:** `src/index.html`을 브라우저로 바로 엽니다(`file://` 가능). 서버를 쓰려면 `cd src && python -m http.server 8000`처럼 정적 서버면 충분합니다.
- **단일 파일 빌드:** `python tools/build_single.py`를 실행하면 `dist/Chalna_PartsOfUs.html`이 다시 만들어집니다. Python 3.8 이상만 있으면 되고 추가 설치는 없습니다.
  - 동작 방식: 소스에서 따옴표, 괄호, `&quot;` 바로 뒤에 오는 `assets/...` 경로를 data URI로 바꿉니다.
  - 새 이미지 경로를 추가할 때도 `"assets/..."`나 `url("assets/...")` 형태로 쓰면 자동으로 포함됩니다.
- **외부 의존성:** 웹폰트 CDN만 씁니다(§3-4). **오프라인 전시라면 폰트를 로컬화해야 합니다** (§6-1).
- **브라우저:** Chrome 최신 버전 기준으로 검수했습니다. CSS `mask-image`(로고, 호버 원형 마스크)와 `aspect-ratio`를 쓰므로 최신 Chromium, Safari, Firefox가 필요합니다.

## 2. 화면 구조와 라우팅

해시 라우팅입니다. `route()`가 `location.hash`를 읽고 `show(viewId)`로 `.view` 섹션 하나에만 `.on`을 붙입니다.

| 해시 | 섹션 id | 화면 | 주요 동작 |
|---|---|---|---|
| (없음) / `#intro` | `intro` | 레이스 봉투 → 편지 | 봉투 클릭(또는 Enter/Space) → 덮개 열림 → 편지지가 올라오며 `.reader` 스크롤 편지로 전환 → 맨 아래까지 스크롤하면 자동으로 `#collection` 이동 |
| `#collection` | `main` | 컬렉션 메인 (키비주얼) | 병 5개 위 투명 핫스팟(`#hots`). 호버하면 해당 병 외 영역에 크림색 덮개와 원형 마스크, 작품 레터링과 저자 정보 표시. 왼쪽 아래 목록(`#indexList`)도 같은 동작. 클릭하면 `#work-N` |
| `#work-1` ~ `#work-5` | `detail` | 작품 상세 | 왼쪽 사진 갤러리(◀ ▶, 키보드 ←/→). 오른쪽에 제목, 명대사, The Story, Scent Notes를 순차 배치하고 **넘치면 오른쪽 텍스트 영역만 스크롤**. 하단 Previous · 점 · Next. 오른쪽 위 "컬렉션으로 돌아가기". Esc → `#collection` |
| `#story` | `story` | 브랜드 스토리 6페이지 | 휠, 키보드(↑↓, PgUp/PgDn, Space), 터치로 **한 번에 한 화면씩** 넘김(950ms 잠금). 우측 진행 바 `#sBar` |
| `#contact` | `contact` | 연락처 | 정적 페이지 |

- **GNB:** Collection / Brand Story / Contact. 상세 화면에서는 Collection이 활성 상태로 표시됩니다.
- **화면별 배경색:** `show()` 안의 맵을 씁니다. intro, detail, contact는 `#0f0a05`, main은 `#dcd8d2`, story는 `#15120f`입니다.
- **1분 대기 후 복귀:** `IDLE_MS = 60000` 동안 `mousemove, mousedown, wheel, keydown, touchstart, touchmove` 입력이 없으면 `history.replaceState` 후 `#intro`로 돌아가고 봉투가 닫힌 상태로 초기화됩니다. 전시 키오스크 용도입니다.
- **스케일링:** `fit()`이 `S = min(innerWidth/2560, innerHeight/1440)`을 계산하고 `#stage`에 `translate(-50%,-50%) scale(S)`를 적용합니다. **모든 CSS 수치는 2560×1440 기준 px입니다.**
- **커스텀 커서:** `#cursor`는 레이스 화살표 이미지입니다. 화살표 끝이 클릭 지점이고, 크기는 변하지 않습니다.

### 메인 키비주얼 위 병 좌표 (`WORKS[i].box` = [x, y, w, h], 2560×1440 기준)

```
1 데미안            [550, 500, 390, 550]
2 노인과 바다       [960, 224, 350, 556]
3 오만과 편견       [1444, 200, 392, 550]
4 향수              [1080, 750, 550, 460]
5 고도를 기다리며   [1720, 540, 460, 540]
```

> ⚠️ 2026-11-19에 메인 사진(`main.jpg`)을 **새 은쟁반 사진으로 바꿨지만 좌표는 아직 이전 사진 기준입니다.** 새 사진의 병 위치에 맞게 다시 재야 합니다 (§6-2).

## 5. 확정된 디자인 결정 (변경 금지 · 클라이언트 요청)

### 유지할 것

- 상세 오른쪽 텍스트는 **명대사 → 소설 설명 → 향 설명** 순서로 배치하고, 넘치면 **오른쪽 텍스트 영역만** 스크롤합니다.
- 상세 갤러리 순서 규칙(§3-2). 일러스트는 항상 마지막입니다.
- 버튼은 **한국어 명조체 텍스트만** 씁니다(레이스 테두리 없음). "컬렉션 보기"는 스토리 마지막 페이지, "컬렉션으로 돌아가기"는 상세 오른쪽 위에 있습니다.
- 브랜드 스토리는 **브랜드 소개**입니다. 컬렉션(Parts of Us) 설명을 섞지 마세요.
- 1분 대기 후 첫 화면 복귀.

### 하지 말 것 (클라이언트가 명시적으로 거절함)

- 기획서·PPT처럼 보이는 구성: 문제/해결 표, #1 #2 번호 칸, 말풍선 칩, 긴 페이지
- 상세 화면의 GNB, 오브제·꽃 정보 표기, 호버 시 병이 들리는 효과
- 밝고 꽉 찬 레이스 덩어리 같은 무겁고 촌스러운 장식
- 사진을 배경 전체에 까는 처리 (스토리 01·02는 카드형 1000×826)
